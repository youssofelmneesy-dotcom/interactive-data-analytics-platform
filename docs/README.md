# Interactive Data Analytics Platform

A professional, portfolio-grade web application for uploading, cleaning, visualizing, and gaining AI-powered insights from data.

## Features

- **Upload**: Drag-and-drop CSV/Excel file upload
- **Clean**: Automatic data quality analysis and cleaning
- **Visualize**: Interactive dashboards with multiple chart types
- **AI Insights**: Gemini-powered summaries and anomaly detection
- **Export**: Professional PDF report generation

## Tech Stack

**Frontend**: React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Router, TanStack Query, Apache ECharts

**Backend**: FastAPI, Python, Pandas, SQLite, Playwright

**AI**: Gemini API

**Deployment**: Vercel (Frontend), Render (Backend)
